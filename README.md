# Sua agenda

Agenda de serviços para barbearia. Permite cadastrar clientes, serviços e profissionais e marcar horários.

Trabalho prático de Desenvolvimento Web I, Universidade do Contestado (UnC).

## Integrantes

| Nome | Responsabilidade |
| --- | --- |
| _Nome completo 1_ | _ex.: navegação, clientes, README_ |
| _Nome completo 2_ | _ex.: serviços, profissionais, validações_ |
| _Nome completo 3_ | _ex.: agendamentos, dashboard, funcionalidade exclusiva_ |

## Funcionalidades

- Navegação entre 5 telas: Início, Agendamentos, Clientes, Serviços e Profissionais
- _(em construção, ver [docs/planejamento.md](docs/planejamento.md))_

## Tecnologias

- HTML5, CSS3 e JavaScript puro
- Bootstrap 5 (via CDN)
- localStorage para guardar os dados

## Como executar

1. Baixe ou clone o repositório.
2. Abra o arquivo `index.html` no navegador.

## Estrutura de pastas

```
index.html        página principal
css/style.css     estilos próprios
js/app.js         navegação entre as telas
assets/img/       imagens
docs/             planejamento do projeto
```
